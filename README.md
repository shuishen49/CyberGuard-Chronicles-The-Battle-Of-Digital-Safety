# 网络安全意识游戏（CyberSecurity Awareness Game）

[**在线游玩**](https://ayush712gupta.github.io/CyberSecurityAwarenessGame/)

*一款以趣味互动方式学习并实践网络安全概念的游戏。*

---

## 项目简介
**网络安全意识游戏** 是一款互动式教育游戏，旨在帮助用户学习并实践关键的网络安全概念。游戏通过测验、模拟和剧情挑战吸引玩家，提高大家对在线安全威胁的认知。游戏内集成了聊天机器人，可在游玩过程中提供指导与帮助。

本项目非常适合学生、初学者，以及任何希望以有趣方式提升网络安全知识的人。

---

## 功能特色
- 涵盖网络安全核心概念的 **互动测验**
- 帮助实战理解攻击的 **模拟游戏**
- 通过 **剧情化学习** 展示真实世界的网络安全威胁
- 提供提示、指导与互动学习的 **Botpress 聊天机器人**
- 兼容桌面与移动设备的 **响应式设计**
- 简洁友好的 **用户界面**，带来流畅的学习体验

---

## 涵盖主题
### **初级**
- 网络安全入门
- 密码强度测试
- 双因素认证
- 网络卫生模拟

### **中级**
- 钓鱼攻击防御模拟
- 加密与解密模拟
- 数字足迹模拟

### **高级**
- SQL 注入游戏
- 中间人攻击
- 暴力破解攻击模拟
- 跨站脚本攻击

---

## 使用技术
- **前端：** HTML、CSS、JavaScript、ReactJS
- **后端：** 本地 JavaScript（可选 Node.js）
- **聊天机器人：** Botpress
- **版本控制：** Git 与 GitHub
